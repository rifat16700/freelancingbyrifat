Universal External Proxy Hosting + Cloudflare 5-Min Cache Setup

যেকোনো হোস্টিংয়ে (AlwaysData, cPanel, DirectAdmin বা VPS) মাত্র ৪টি তথ্য বসিয়ে আপনার সাইটের ডাটা ফেচ, ১০০-প্রোডাক্ট চ্যাঙ্কিং, সিঙ্গেল প্রোডাক্ট ও চেকআউট ফেচ এবং Cloudflare 5-Min Edge Caching সেটআপ করার সম্পূর্ণ গাইড।

★ এই প্রক্সি ও ক্যাশিং আর্কিটেকচার কীভাবে কাজ করে?

⚡ ক্যাশিংয়ের আসল নিয়ম: প্রক্সি কোনো ফাইল সেভ বা ডিস্কে ক্যাশ করে না। প্রক্সি সম্পূর্ণ Stateless! প্রক্সির একমাত্র কাজ হলো যখনই Cloudflare Edge-এ Cache Miss হবে, তখন D1 ডাটাবেজ থেকে ডাটা ফেচ করে JSON আকারে ক্লাউডফ্লেয়ার ও ব্রাউজারকে দেওয়া। আর ক্যাশ করে ধরে রাখার পুরো দায়িত্ব Cloudflare Edge Cache (৫ মিনিট)-এর। ফলে Alwaysdata-র ফ্রি হোস্টিং বা যেকোনো হোস্টিংয়ের রিসোর্সের ওপর কোনো চাপই পড়ে না!

📦 ১. Master JSON + 100-Product Chunks

হোম ও শপ পেজে প্রোডাক্ট লোড করার সময় প্রক্সি D1 থেকে ডাটা ফেচ করে ১০০টি করে প্রোডাক্ট চ্যাঙ্কে (product_chunks) সাজিয়ে JSON আকারে Cloudflare-কে দেয়। Cloudflare এই JSON-কে ৫ মিনিট ক্যাশ করে রাখে এবং সাইট ওই JSON-টাকেই ডাটাবেজ হিসেবে ব্যবহার করে।

🎯 ২. প্রোডাক্ট পেজ: ক্যাশ থাকলে ওখান থেকেই, নাহলে Single Fetch

কাস্টমার প্রোডাক্ট পেজে (/product?id=...) গেলে ৫ মিনিটের ক্যাশ করা Master JSON থাকলে সেখান থেকেই প্রোডাক্ট নিয়ে দেখাবে। আর সরাসরি প্রোডাক্ট লিংকে ঢুকলে বা Cache Miss হলে পুরো ডাটাবেজ না টেনে প্রক্সি শুধুমাত্র ওই ১টি প্রোডাক্টই ফেচ করবে!

🛒 ৩. চেকআউট পেজে শুধুই চেকআউট ডাটা

চেকআউট পেজে (/checkout) প্রোডাক্ট ক্যাটালগ লোড না করে শুধুমাত্র ডেলিভারি জোন, প্রোমো কোড ও পেমেন্ট সেটিংস ফেচ হয়। আর Order Confirm আগের মতোই সরাসরি Cloudflare Function (/api/save-order) হ্যান্ডেল করে।

🔒 ৪. ডোমেইন হোয়াইটলিস্ট ও D1 API Token

ক্লাউডফ্লেয়ার সাধারণ ব্রাউজার রিকোয়েস্টে CORS ব্লক করে—তাই প্রক্সিতে D1:Read API Token দেওয়া থাকে এবং ALLOWED_SITE_URL দিয়ে আপনার মেইন সাইট ছাড়া অন্য যেকোনো ডোমেইনের রিকোয়েস্ট ৪০৩ দিয়ে ব্লক করা থাকে।

১ Cloudflare থেকে প্রয়োজনীয় ৩টি তথ্য কোথায় পাবেন?

প্রক্সি ফাইলটি Cloudflare D1 ডাটাবেজ থেকে ডাটা পড়ার জন্য নিচের ৩টি তথ্য লাগবে:

১. CF_ACCOUNT_ID (Account ID)

  • Cloudflare Dashboard-এ লগইন করুন।
  • বাম পাশের মেনু থেকে Workers & Pages-এ যান।
  • ডান পাশের সাইডবারে Account ID দেখতে পাবেন — ক্লিক করে কপি করুন।

২. CF_D1_DATABASE_ID (Database ID)

  • Cloudflare Dashboard-এর বাম মেনু থেকে Workers & Pages → D1 SQL Database-এ যান।
  • আপনার ডাটাবেজটিতে ক্লিক করুন।
  • উপরে Database ID দেখতে পাবেন (যেমন: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx) — কপি করুন।

৩. CF_API_TOKEN (D1:Read Permission সহ API Token তৈরির নিয়ম)

কেন API Token লাগবে? Cloudflare D1 ডাটাবেজকে বাইরের হোস্টিং (যেমন AlwaysData বা cPanel) থেকে সরাসরি ব্রাউজার কল করলে ব্লক করে দেয়। তাই একটি Read-Only API Token তৈরি করে প্রক্সি ফাইলে দিতে হবে যাতে প্রক্সি নিরাপদে ডাটাবেজ পড়তে পারে।
  • Cloudflare Dashboard-এর একদম উপরের ডান কোণায় Profile Icon → My Profile → API Tokens-এ যান (অথবা সরাসরি dash.cloudflare.com/profile/api-tokens লিংকে যান)।
  • Create Token বাটনে ক্লিক করুন → নিচে Create Custom Token-এর পাশে Get started-এ ক্লিক করুন।
  • Token name: যেকোনো নাম দিন (যেমন: Ranonex-Proxy-D1-Read)।
  • Permissions: প্রথম বক্সে Account সিলেক্ট করুন → দ্বিতীয় বক্সে D1 সিলেক্ট করুন → তৃতীয় বক্সে Read সিলেক্ট করুন।
  • নিচে Continue to summary → Create Token-এ ক্লিক করুন এবং যে টোকেনটি দেখাবে সেটি কপি করে নিচের বক্সে বসান।

৩ হোস্টিংয়ে কীভাবে সেটআপ করবেন? (AlwaysData ও Custom Hosting গাইড)

☁️ AlwaysData হোস্টিংয়ে সেটআপ করার নিয়ম (ফ্রি ও পেইড উভয় প্ল্যানে)

AlwaysData ড্যাশবোর্ডে (admin.alwaysdata.com) লগইন করে নিচের সহজ ধাপগুলো ফলো করুন:

  • ধাপ ১ (ফোল্ডার ওপেন): AlwaysData-র বাম পাশের মেনু থেকে Files-এ ক্লিক করুন → www/ ফোল্ডারে ঢুকুন।
  • ধাপ ২ (ফাইল আপলোড বা এডিট):
    • সেখানে আগে থেকে থাকা index.html বা অন্য ডেমো ফাইল থাকলে মুছে দিন।
    • উপরের Upload বাটনে ক্লিক করে জেনারেট করা index.php এবং .htaccess ফাইল দুটি আপলোড করে দিন। (অথবা New file বানিয়ে index.php নাম দিয়ে কোডটি পেস্ট করে সেভ করুন)।
  • ধাপ ৩ (প্রক্সি লিংক নেওয়া):
    • বাম পাশের মেনু থেকে Web → Sites-এ যান।
    • সেখানে আপনার সাইটের অ্যাড্রেস দেখতে পাবেন (যেমন: https://accountname.alwaysdata.net)।
    • এটিই হলো আপনার প্রক্সি URL! (ব্রাউজারে https://accountname.alwaysdata.net/api/public-data ওপেন করে চেক করলেই ডাটা দেখতে পাবেন)।
💡 AlwaysData রিসোর্স পারফরম্যান্স: AlwaysData-র ফ্রি প্ল্যানে (0.25 CPU, 500MB RAM) এটি হাজার হাজার ভিজিটর অনায়াসে হ্যান্ডেল করতে পারবে। কারণ কাস্টমাররা সরাসরি AlwaysData-তে হিট করে না—কাস্টমাররা হিট করে Cloudflare Edge-এ। Cloudflare প্রতি ৫ মিনিটে মাত্র ১ বার AlwaysData থেকে ফ্রেশ ডাটা টেনে নিয়ে বাকি সব কাস্টমারকে নিজের ক্যাশ থেকে সরবরাহ করে!

🌐 Custom Hosting (cPanel / DirectAdmin / CyberPanel / VPS)-এ সেটআপের নিয়ম

আপনার নিজস্ব সিপ্যানেল বা যেকোনো হোস্টিং প্যানেলে সেটআপ করার নিয়ম:

  • ধাপ ১: cPanel বা হোস্টিং প্যানেলে লগইন করে File Manager খুলুন।
  • ধাপ ২: আপনার ডোমেইনের রুট ফোল্ডারে (public_html/) অথবা যদি সাবডোমেইনে প্রক্সি রাখতে চান (যেমন: api.yourdomain.com), তবে সেই সাবডোমেইনের ফোল্ডারে ঢুকুন।
  • ধাপ ৩: জেনারেট করা index.php এবং .htaccess ফাইল দুটি আপলোড করুন।
  • ধাপ ৪: ব্যাস! আপনার কাস্টম প্রক্সি URL হবে https://yourdomain.com বা https://api.yourdomain.com।

৪ Cloudflare Pages-এ প্রক্সি লিংক যুক্ত করুন

আপনার মেইন ওয়েবসাইট যেন ক্লাউডফ্লেয়ার ফাংশনের বদলে আপনার প্রক্সি হোস্টিং থেকে ডাটা আনে, সেজন্য Cloudflare Pages-এ ১টি Environment Variable যোগ করুন:

  • Cloudflare Dashboard → Workers & Pages → আপনার ওয়েবসাইট প্রজেক্টে ক্লিক করুন।
  • উপরে Settings → Environment variables-এ যান।
  • Add variable-এ ক্লিক করে নিচের মতো বসান:
    Variable name: PROXY_API_URL
    Value: https://your-account.alwaysdata.net (শেষে স্ল্যাশ / দেবেন না)
  • Save করুন এবং Deployments ট্যাবে গিয়ে Retry deployment দিন। ব্যাস, কাজ শেষ!

৫ Cloudflare 5-Min Domain Cache Rule, Subdomain (`shop.domain.com`) এবং `www.` Redirect

ক) `www.` থেকে মেইন ডোমেইনে 301 Redirect (যাতে `www` ও ছাড়া আলাদা ২ বার ক্যাশ না হয়)

  • Cloudflare Dashboard-এ আপনার ডোমেইনে ক্লিক করুন → বাম মেনু থেকে Rules → Redirect Rules-এ যান।
  • Create rule-এ ক্লিক করুন:
    • Rule name: Redirect www to root
    • When incoming requests match: Custom filter expression → Field: Hostname, Operator: equals, Value: www.ranonex.shop
    • Then: Type: Dynamic, Expression: concat("https://ranonex.shop", http.request.uri.path), Status code: 301, Preserve query string: ✅ Check দিন।

খ) ৫ মিনিটের Cloudflare Cache Rule (মেইন ডোমেইন অথবা শুধুই `shop.domain.com` সাবডোমেইনের জন্য)

  • Cloudflare-এ আপনার ডোমেইনে ঢুকে বাম মেনু থেকে Caching → Cache Rules → Create rule-এ যান।
  • যদি মেইন ডোমেইনে সাইট থাকে:
    • Field: URI Path → Operator: starts with → Value: /api/public-data (এবং OR দিয়ে /api/checkout-data ও /api/public-reviews)।
  • যদি আপনার মেইন ডোমেইন ব্র্যান্ড ডোমেইন হয় এবং শপটি `shop.domain.com` সাবডোমেইনে থাকে:
    • হ্যাঁ! আপনি শুধুমাত্র ওই সাবডোমেইনটির জন্যই ক্যাশিং করাতে পারবেন। ফিল্টারে দিন:
    (http.host eq "shop.domain.com") — তাহলে মেইন ব্র্যান্ড ডোমেইনে কোনো প্রভাব না ফেলেই শুধুমাত্র shop.domain.com-এর সব ডাটা ক্যাশ হবে!
  • Cache eligibility: Eligible for cache সিলেক্ট করুন।
  • Edge TTL: Override origin সিলেক্ট করে 5 minutes দিন।
  • Browser TTL: 1 minute দিয়ে Deploy করুন!
