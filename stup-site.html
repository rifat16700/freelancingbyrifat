⚙️ OFFICIAL SETUP & CONFIGURATION HUB (/stup-site)

Universal External Proxy Hosting + Smart JSON Database Setup

যেকোনো প্যানেল বা হোস্টিংয়ে (AlwaysData, cPanel, DirectAdmin, VPS, Node.js বা PHP) মাত্র ৪টি তথ্য বসিয়ে আপনার সাইটের ডাটা ফেচ, ১০০-প্রোডাক্ট চ্যাঙ্কিং, সিঙ্গেল প্রোডাক্ট ফেচ, চেকআউট ডাটা ফেচ এবং Cloudflare 5-Min Edge Caching সেটআপ করার সম্পূর্ণ গাইড।

★ এই নতুন প্রক্সি ও JSON সিস্টেম কীভাবে কাজ করে?

📦 ১. Master JSON + 100-Product Chunks

হোম ও শপ পেজে প্রোডাক্ট লোড করার সময় প্রক্সি সার্ভার ১০০টি করে প্রোডাক্ট চ্যাঙ্কে (chunk_1.json, chunk_2.json...) ভাগ করে master_main.json ফাইলে রাখে এবং সেই JSON ফাইলকেই ডাটাবেজ হিসেবে ব্যবহার করে।

🎯 ২. সিঙ্গেল প্রোডাক্ট পেজে শুধু ১টি প্রোডাক্ট ফেচ

কাস্টমার যখন কোনো প্রোডাক্ট পেজে (/product?id=...) ঢুকবে এবং ক্যাশ মিস হবে, তখন পুরো ডাটাবেজ ফেচ না করে প্রক্সি শুধুমাত্র ওই ১টি প্রোডাক্ট ও তার রিলেটেড প্রোডাক্ট ফেচ করবে (product_<id>.json)।

🛒 ৩. চেকআউট পেজে শুধুই চেকআউট ডাটা

চেকআউট পেজে (/checkout) প্রোডাক্ট ক্যাটালগ লোড না করে শুধুমাত্র ডেলিভারি জোন, প্রোমো কোড ও পেমেন্ট সেটিংস (checkout_main.json) কল করা হয়। আর **Order Confirm** আগের মতোই সরাসরি Cloudflare Function (/api/save-order) হ্যান্ডেল করে।

🔒 ৪. ডোমেইন হোয়াইটলিস্ট ও D1 API Token

Cloudflare সাধারণ ব্রাউজার রিকোয়েস্টে CORS এরর দেয়—তাই প্রক্সি সার্ভারে D1:Read পারমিশনসহ API Token দেওয়া থাকে এবং ALLOWED_SITE_URL দিয়ে আপনার মেইন সাইট ছাড়া অন্য সব ডোমেইন ব্লক করা থাকে।

১ Cloudflare থেকে প্রয়োজনীয় ৩টি তথ্য কোথায় ও কীভাবে পাবেন?

প্রক্সি ফাইলটি Cloudflare D1 ডাটাবেজ থেকে ডাটা পড়ার জন্য নিচের ৩টি জিনিস লাগবে:

১. CF_ACCOUNT_ID (Account ID)

  • Cloudflare Dashboard-এ লগইন করুন।
  • বাম পাশের মেনু থেকে Workers & Pages-এ যান।
  • ডান পাশের সাইডবারে Account ID লেখা দেখবেন — ক্লিক করে কপি করুন।

২. CF_D1_DATABASE_ID (Database ID)

  • Cloudflare Dashboard-এর বাম মেনু থেকে Workers & Pages → D1 SQL Database-এ যান।
  • আপনার স্টোরের ডাটাবেজটিতে ক্লিক করুন।
  • উপরে Database ID দেখতে পাবেন (যেমন: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx) — কপি করুন।

৩. CF_API_TOKEN (D1:Read Permission সহ API Token তৈরির নিয়ম)

কেন API Token লাগবে? Cloudflare D1 ডাটাবেজকে বাইরের হোস্টিং (যেমন AlwaysData বা cPanel) থেকে সরাসরি কল করলে ব্লক করে দেয়। তাই একটি Read-Only API Token তৈরি করে প্রক্সি ফাইলে দিতে হবে যাতে প্রক্সি নিরাপদে ডাটাবেজ পড়তে পারে।
  • Cloudflare Dashboard-এর একদম উপরের ডান কোণায় Profile Icon → My Profile → API Tokens-এ যান (অথবা সরাসরি dash.cloudflare.com/profile/api-tokens লিংকে যান)।
  • Create Token বাটনে ক্লিক করুন → নিচে Create Custom Token-এর পাশে Get started-এ ক্লিক করুন।
  • Token name: যেকোনো নাম দিন (যেমন: Ranonex-Proxy-D1-Read)।
  • Permissions: প্রথম বক্সে Account সিলেক্ট করুন → দ্বিতীয় বক্সে D1 সিলেক্ট করুন → তৃতীয় বক্সে Read সিলেক্ট করুন।
  • নিচে Continue to summary → Create Token-এ ক্লিক করুন এবং যে টোকেনটি দেখাবে সেটি কপি করে নিচের বক্সে বসান।

২ ১-ক্লিক প্রক্সি ফাইল জেনারেটর (PHP ও Node.js)

নিচের ৪টি ঘরে আপনার তথ্য বসালে নিচের প্রক্সি কোড অটোমেটিক আপডেট হয়ে যাবে। এরপর Copy Code বা Download File বাটনে ক্লিক করে আপনার হোস্টিংয়ে আপলোড করুন:

হোস্টিংয়ে আপলোড করার নিয়ম:
• PHP হোস্টিং (AlwaysData / cPanel): আপনার হোস্টিংয়ের রুট ফোল্ডারে (www/ বা public_html/) উপরের index.php এবং .htaccess ফাইল দুটি আপলোড করে দিন। প্রক্সি নিজে থেকেই json_db/ ফোল্ডার বানিয়ে ১০০টি করে প্রোডাক্টের মাস্টার JSON ও সিঙ্গেল প্রোডাক্ট JSON ক্যাশ করে রাখবে!
• Node.js হোস্টিং: server.js ফাইলটি আপলোড করে রান কমান্ডে node server.js দিন।

৩ Cloudflare Pages-এর Environment Variable-এ প্রক্সি লিংক যুক্ত করুন

আপনার মেইন ওয়েবসাইট যেন ফাংশনের বদলে আপনার প্রক্সি হোস্টিং থেকে ডাটা আনে, সেজন্য Cloudflare-এ শুধু ১টি Environment Variable যোগ করুন:

  • Cloudflare Dashboard → Workers & Pages → আপনার ওয়েবসাইট প্রজেক্টে ক্লিক করুন।
  • উপরে Settings → Environment variables-এ যান।
  • Add variable-এ ক্লিক করে নিচের মতো বসান:
    Variable name: PROXY_API_URL
    Value: https://your-proxy-domain.alwaysdata.net (শেষে / দেবেন না)
  • Save করুন এবং Deployments ট্যাবে গিয়ে Retry deployment দিন। ব্যস!

৪ Cloudflare 5-Min Domain Cache Rule, Subdomain (`shop.domain.com`) এবং `www.` Redirect

ক) `www.` থেকে মেইন ডোমেইনে 301 Redirect (যাতে `www` ও ছাড়া আলাদা ২ বার ক্যাশ না হয়)

  • Cloudflare Dashboard-এ আপনার ডোমেইনে ক্লিক করুন → বাম মেনু থেকে Rules → Redirect Rules (অথবা Overview → Bulk Redirects / Single Redirects)-এ যান।
  • Create rule-এ ক্লিক করুন:
    • Rule name: Redirect www to root
    • When incoming requests match: Custom filter expression → Field: Hostname, Operator: equals, Value: www.ranonex.shop
    • Then: Type: Dynamic, Expression: concat("https://ranonex.shop", http.request.uri.path), Status code: 301, Preserve query string: ✅ Check দিন।

খ) ৫ মিনিটের Cloudflare Cache Rule (মেইন ডোমেইন অথবা শুধুই `shop.domain.com` সাবডোমেইনের জন্য)

  • Cloudflare-এ আপনার ডোমেইনে ঢুকে বাম মেনু থেকে Caching → Cache Rules → Create rule-এ যান।
  • যদি মেইন ডোমেইনে সাইট থাকে:
    • Field: URI Path → Operator: starts with → Value: /api/public-data (এবং OR দিয়ে /api/checkout-data ও /api/public-reviews)।
  • যদি আপনার মেইন ডোমেইন ব্র্যান্ড ডোমেইন হয় এবং শপটি `shop.domain.com` সাবডোমেইনে থাকে:
    • হ্যাঁ! আপনি শুধুমাত্র ওই সাবডোমেইনটির জন্যই ক্যাশিং করাতে পারবেন। ফিল্টারে দিন:
    (http.host eq "shop.domain.com") — তাহলে মেইন ব্র্যান্ড ডোমেইনে কোনো প্রভাব না ফেলেই শুধুমাত্র shop.domain.com-এর সব ডাটা ক্যাশ হবে!
  • Cache eligibility: Eligible for cache সিলেক্ট করুন।
  • Edge TTL: Override origin সিলেক্ট করে 5 minutes দিন।
  • Browser TTL: 1 minute দিয়ে Deploy করুন!
